# Rock Paper Scissors Game

A simple console-based Rock Paper Scissors game developed using Java.

## Features
- Player can choose Rock, Paper, or Scissors.
- Computer randomly selects a move.
- Automatically determines the winner.
- Detects invalid player input.
- Allows the player to play again.

## Technologies Used
- Java
- Scanner
- Random
- Do-while loop
- Conditional statements

## Game Rules
- Rock beats Scissors.
- Scissors beats Paper.
- Paper beats Rock.
- Same choices result in a tie.

## How to Run
```bash
cd src
javac Main.java
java Main
```
